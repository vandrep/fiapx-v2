# Documentação de domínio

Este é um repositório de contexto único. Antes de explorar ou modificar uma área,
leia os documentos aplicáveis:

- [`CONTEXT.md`](../../CONTEXT.md): glossário canônico do domínio;
- [`docs/adr/`](../adr/): decisões arquiteturais;
- os contratos em `docs/contratos/`, quando o trabalho tocar HTTP ou mensageria.

Use os termos definidos em `CONTEXT.md` em tickets, hipóteses, testes, código e
documentação. Se um conceito necessário não estiver no glossário, registre a lacuna
para `domain-modeling` em vez de introduzir um sinônimo sem decisão.

Se uma proposta contrariar um ADR, declare o conflito e a razão para reabrir a
decisão antes de mudar sua implementação.
