# Rótulos de triagem

As skills usam cinco papéis canônicos. No rastreador Markdown local, registre o
rótulo correspondente no campo `label` do ticket.

| Papel da skill | Rótulo no rastreador | Significado |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A solicitação precisa de avaliação do mantenedor. |
| `needs-info` | `needs-info` | Aguarda informações de quem a reportou. |
| `ready-for-agent` | `ready-for-agent` | Está especificada e pode ser executada por um agente. |
| `ready-for-human` | `ready-for-human` | Exige execução ou decisão humana. |
| `wontfix` | `wontfix` | Não será realizada. |
